# Pharmacy Management System by khadidja <3

A Java-based application for managing pharmacy operations including:
- Client management
- Supplier management
- Medication inventory
- Order processing
- Sales tracking

## Features
- Client registration and history tracking
- Supplier management
- Medication stock management with expiration date tracking
- Order processing and delivery tracking
- Sales with prescriptions

## How to Run
1. Clone the repository
2. Open in IntelliJ IDEA or your preferred Java IDE
3. Run the `Main.java` file

## Requirements
- Java 8 or higher
- Swing library (included in standard Java)
